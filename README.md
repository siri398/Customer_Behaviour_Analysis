# Customer_Behaviour_Analysis
📌 Overview

This project analyzes customer shopping behavior using Python, Pandas, and SQL. The objective is to clean and transform customer transaction data, perform exploratory analysis, answer business questions using SQL, and generate insights related to customer spending, products, discounts, subscriptions, and customer segments.

The dataset contains 3,900 customer records and 18 original columns. After data transformation, additional features such as age_group and purchase_frequency_days were created, resulting in 19 columns.

🧹 Data Cleaning & Feature Engineering

The following transformations were performed:

Checked dataset structure using df.info()
Performed statistical analysis using df.describe()
Identified missing values
Filled missing Review Rating values using category-wise median
Standardized column names to lowercase
Replaced spaces with underscores
Renamed purchase_amount_(usd) to purchase_amount
Removed the promo_code_used column
Created age_group
Created purchase_frequency_days based on purchase frequency

The age_group feature was created using quartile-based segmentation with four groups: Young Adult, Adult, Middle-aged, and Senior.

🗄️ SQL Analysis

The cleaned dataset was loaded into a SQLite customer table with 19 columns.

SQL was used to answer business questions such as:

Revenue generated by male vs. female customers
Customers who used discounts but spent above average
Top 5 products based on average review rating
Average purchase amount for Standard vs. Express shipping
Spending behavior of subscribed vs. non-subscribed customers
Products with the highest discount rates
Customer segmentation into New, Returning, and Loyal
Top products within each category
Subscription behavior among repeat buyers
Revenue contribution by age group

📈 Key Insights

Some important findings from the analysis:

Male customers generated higher total revenue than female customers.
Customers who used discounts still included many high-value purchases; 839 customers met the discount + above-average spending condition.
Gloves had the highest average product rating at 3.86, followed by Sandals and Boots.
Express shipping had a slightly higher average purchase amount ($60.48) than Standard shipping ($58.46).
The dataset contained 3,116 Loyal, 701 Returning, and 83 New customers according to the project's segmentation logic.
Young Adults contributed the highest revenue among the age groups, with $62,143.
